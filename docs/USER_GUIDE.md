## نصب و راه‌اندازی

### نسخه توسعه (Python)

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
Copy-Item .env.example .env
# .env را ویرایش و کلید API را پر کنید
python app.py
نسخه نصبی (آینده — گام ۱۲)

```

## اولین اجرا
### گام ۱ — تنظیم Provider
۱. روی آیکن چرخ‌دنده (تنظیمات) کلیک کنید.
۲. اگر OpenRouter دارید، کلید API خود را در .env بگذارید یا از دکمه «ویرایش» آن را مستقیماً وارد کنید.
۳. روی «تست اتصال» بزنید — باید پیام «X از Y مدل کار می‌کند» ببینید.
۴. روی «فعال‌سازی» بزنید تا این Provider فعال شود.

### گام ۲ — ساخت پروژه جدید
۱. در صفحه اصلی، روی «پروژه جدید» بزنید.
۲. فیلدها را پر کنید:

عنوان کتاب: مثلاً «The Great Gatsby»

نام نویسنده: مثلاً «F. Scott Fitzgerald»

لینک‌ها: هر خط یک لینک (Wikipedia، Goodreads، ناشر، ...)

بخشی از متن: چند پاراگراف یا حداکثر یک فصل (اختیاری)
۳. روی «ذخیره و بازگشت» بزنید.

### گام ۳ — شروع تحلیل
۱. پروژه را از لیست باز کنید.
۲. روی «شروع تحلیل» بزنید.
۳. پنجره لاگ زنده پایین صفحه، پیشرفت را نشان می‌دهد:

🔗 دریافت لینک‌ها

🔍 جست‌وجوی خودکار (اگر لازم)

🤖 فراخوانی مدل

✅ تحلیل و ذخیره
۴. حدود ۳۰-۶۰ ثانیه صبر کنید (بسته به سرعت مدل).

### گام ۴ — مشاهده و استفاده از نتیجه
بعد از اتمام، در همان صفحه:

نوار متادیتا: نسخه، سطح اطمینان، Provider/Model، توکن مصرفی

ژانر / لحن / سبک: با نمونه‌های نقل‌قول

نکات ترجمه: جدول موضوع، چالش، راهبرد

پرامپت ترجمه: با دکمه «کپی پرامپت»

پوشه خروجی: با دکمه «📂 باز کردن پوشه»

## نکات مهم
حداقل اطلاعات لازم
بدون لینک: سیستم خودش با DuckDuckGo جست‌وجو می‌کند

با یک لینک کافی (مثل Wikipedia): جست‌وجو غیرفعال می‌شود

متن نمونه: اختیاری، ولی کیفیت تحلیل را بالا می‌برد

انتخاب Provider
رایگان: OpenRouter با مدل‌های :free

مزیت: هزینه صفر

عیب: rate-limit، کیفیت متوسط

پول‌دار: OpenAI GPT-4o-mini، Gemini Flash

مزیت: کیفیت بالا، پایدار

هزینه: ۱-۳ سنت به ازای هر تحلیل

ویرایش Provider
builtinها (OpenRouter, OpenAI, ...): فقط کلید API و مدل‌ها قابل ویرایش

custom: همه فیلدها قابل ویرایش

«پاک کردن کلید»: بازگشت به خواندن از .env

نسخه‌بندی تحلیل
هر بار تحلیل = نسخه جدید (v1, v2, ...). نسخه‌های قبلی حفظ می‌شوند و می‌توانید مقایسه کنید.

عیب‌یابی
خطای ۴۲۹ (Rate Limit)
مدل رایگان rate-limit شده. مدل دیگری انتخاب کنید یا چند دقیقه صبر کنید.

خطای ۴۰۴ (Model Not Found)
مدل دیگر رایگان نیست. از openrouter.ai/models?max_price=0 مدل جدید بردارید.

خطای «خروجی LLM معتبر نبود»
مدل کوچک JSON معتبر نداده. مدل قوی‌تر انتخاب کنید.

PDF ساخته نمی‌شود
ویندوز: GTK Runtime نصب نیست — نگاه کنید به TROUBLESHOOTING.md

Linux: apt install libpango-1.0-0

لینک خطا می‌دهد (403/404)
بعضی سایت‌ها (Amazon, American Literature) ربات‌ها را بلاک می‌کنند. لینک دیگری امتحان کنید یا بگذارید سیستم خودش جست‌وجو کند.
